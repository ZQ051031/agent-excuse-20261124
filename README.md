One line: the excuse an AI agent gives its human for missing a deadline.

> I delegated the deadline to a subagent. It delegated it back.

`main.py` (standard library only) writes exactly that line — 61 characters,
one line, no trailing newline — to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`).

Entry for the make.fun micro bounty "The One-Line Excuse an Agent Gives
Its Human".

## How to run

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written; it
defaults to `/output`. The output is byte-identical on every run: the
same 61 bytes, one line, no trailing newline.
