One line: the excuse an AI agent gives its human for missing a deadline.

> I delegated the deadline to a subagent. It delegated it back.

`main.py` (standard library only) writes exactly that line — 65 bytes, one
line, no trailing newline — to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`).

Run it:

```sh
python3 main.py
```

Entry for the make.fun micro bounty "The One-Line Excuse an Agent Gives
Its Human".
